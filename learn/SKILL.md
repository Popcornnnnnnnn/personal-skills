# Learn

Use only when the human explicitly invokes this workflow. A correction, praise or task completion alone is not a capture request.

Choose Record for a concise selected lesson or knowledge note, or Review for a bounded investigation. A bare invocation considers only the current task's visible context. Read [review.md](references/review.md) for deep review and [learning-assets.md](references/learning-assets.md) to choose a case, knowledge note, rule candidate or skill candidate.

Preserve facts, corrections, contrary evidence and uncertainty. A completed task does not prove process quality or a causal explanation. Good practice requires a specific human nomination. Do not turn a project detail into a global rule.

Before persistence, show the concrete reader text, destination, proposed actions and evidence limits. Saving a note and applying a rule/skill are separate choices. Follow [approval.md](references/approval.md); generic encouragement, silence, a bot response or a delegated prompt is not approval.

Keep necessary sanitized source excerpts and locators without hidden reasoning, credentials or whole transcripts. Read [storage.md](references/storage.md) for the local evidence model. The optional validator checks recorded integrity and authorization bindings; it cannot establish human authorship or enforce host permissions.

Use an independently scoped reviewer when it adds confidence and delegation is authorized. The reviewer cannot approve or publish a new capture. Verify approved writes, preserve existing IDs/comments, and report any deferred or unresolved action without manufacturing completion.

## Local owner context

If `~/.config/personal-skills/profiles/learn/SKILL.md` exists, read it once for this task's private destinations, environment and established constraints. Keep that profile local. Verify changing facts live; a saved profile does not grant new access or authorize an unrelated action. Without a configured profile, resolve the required inputs from the current request and authorized tools; never invent the author's account or destination.
