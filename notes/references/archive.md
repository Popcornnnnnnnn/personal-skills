# Destination contract

Keep actual workspace, data-source and parent IDs in the user's local owner profile or the current authorized task, never in the public skill. A name alone is not a verified target.

Read the live connection identity, existing parent and relevant schema before a write. Reuse the established reading library and its canonical source records. Honor an explicitly chosen project/team destination. If access or identity cannot be resolved, keep the prepared content unsaved and report the missing input; do not fall back to another workspace or create a parallel archive.

The author uses separate destinations for reading articles, journals, recordings and actionable tasks. This is a filing preference, not authorization to create those structures on another account.
