# Separately authorized scheduled processing

A scheduled collector is an owner deployment, not a default of this public skill. Its actual time window, selected recordings, Notion target, quota policy, cleanup grant, failure handling and runtime environment belong in the private owner profile or explicit scheduling request.

Refresh the current recordings and account for the entire authorized scope. Do not recover deleted recordings from old caches, silently expand the window or infer permission to process all active recordings from an on-demand request.

Verify the saved notes and complete transcript coverage before any authorized recording cleanup. Use the normal Voice Memos UI, not direct database/source-file mutation. Preserve failed or uncertain items and report them separately. Background recovery, power leases and notifications require their own actual deployment contract; configuring or publishing this package creates none.
